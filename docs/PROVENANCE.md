# Provenance and licensing

This page records where the code in this repository comes from, how that was checked, and the rules that keep it clean.
It is a statement of engineering practice, not legal advice.

## Position

* git-cross is an **independent implementation**. It runs the standard `git` command line and is written from
  git's documented behavior and our own design. Git Extensions was used as a **reference for the feature set** a complete
  Git GUI offers (what to build), and is credited for that in [NOTICE.md](../NOTICE.md), the README and the app's settings dialog.
* **No upstream source files, resources, translations, icons or documentation text are copied.**
* The product icon is original: generated by `scripts/make-icon.py` (no third-party artwork).
* The UI font (Inter, SIL OFL 1.1) and all NuGet dependencies are listed with license texts in
  [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md); all are permissive and compatible with the MIT License.

without first changing the license of the whole project to GPL-3.0.

## How the "no copied code" claim is verified

`scripts/audit-upstream-overlap.py [path-to-upstream]` compares every line of ours (`src/`, `tests/`) of 45+ characters
(ignoring braces, `using`, comments) with all lines of the upstream C#/XAML sources and fails on any identical line.

| Date | Upstream files | Our files | Identical non-trivial lines |
|---|---|---|---|
| 2026-10-15 | 1,859 | 55 | **0** |

The script was validated with a positive control (a genuine upstream line planted in our tree is reported, exit code 1).
At a looser 28-character threshold the only identical lines were one-line .NET framework idioms
(`RedirectStandardOutput = true,`, `if (!Directory.Exists(path))`, `else if (line.StartsWith('+'))`), which are
not expressive code. Identifiers that coincide with upstream are .NET API names or the obvious name of a git concept.

Re-run it before every release (`scripts/check.sh` does not, because it needs an upstream checkout).

## Rules for contributors

1. **Read upstream for behavior, then write your own code.** Describe what it does (git arguments, output formats,
   edge cases) in your own words; do not paste or transliterate its code, comments, strings or XAML.
2. **Never adapt upstream code, even a little.** It is GPL-3.0; incorporating any of it would make this project a
   derivative work that can only be distributed under the GPL. If you think a piece of upstream code is indispensable,
   open an issue first — the answer is to re-implement it from the behavior, or to change the project's license
   deliberately and visibly.
3. **Do not import**: translations (`.xlf`/Transifex strings), icons (upstream credits Yusuke Kamiyamane, CC BY 3.0 —
   attribution would be mandatory), the Git Extensions logo or name as a product identity.
4. Do not add dependencies without checking the license (permissive only: MIT/BSD/Apache-2.0/OFL — no GPL/LGPL/AGPL
   or "source available" terms in anything we bundle) and regenerate `THIRD-PARTY-NOTICES.md` (`scripts/third-party-notices.py`).
5. Debug-only developer tooling (`AvaloniaUI.DiagnosticsSupport`) must never be part of a release package.

## Open points for the maintainers

* **Product name.** The project is called **git-cross** and does not use the upstream project's name, logo or icon.
  The `git-` prefix is a deliberate nod to git's convention (an executable named `git-cross` on the `PATH` is also
  reachable as `git cross`). *Git* is a trademark of the Software Freedom Conservancy; extensions such as `git-lfs` use the
  same convention, but read the trademark policy at <https://git-scm.com/about/trademark> before any commercial use of the name.
* macOS/Windows packages are unsigned (see RELEASING.md); this is unrelated to licensing.
