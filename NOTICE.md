## Credits — Git Extensions

git-cross is **inspired by [Git Extensions](https://github.com/gitextensions/gitextensions)**, the Windows
graphical Git client that has served its users for many years. Its authors and contributors showed what a practical,
complete Git GUI looks like, and this project exists because that experience deserves to be available on Linux and macOS too.
